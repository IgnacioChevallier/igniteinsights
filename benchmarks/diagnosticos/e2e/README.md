# Diagnósticos end-to-end

Este directorio contiene notas de experimentación y tablas generadas que respaldan el
diagnóstico de precisión. Se ubica junto a los benchmarks porque es evidencia reproducible, no
documentación de entrada al proyecto.

- `notas/`: diseños, decisiones y lectura de cada experimento.
- `datos/`: salidas generadas por los scripts `scripts/diagnostico_*.py`.

La síntesis vigente está en `docs/resultados/pronostico/precision.md` y el estado canónico
en `docs/resultados/modelo/estado.md`.
